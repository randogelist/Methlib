2. SCOPE AGREEMENT: THE REQUIRED CURRENT-CORE PROOF LEMMA
======================================================================

Use the source's total lookup:
  lookupNat [] i = 0;
  lookupNat (x::rho) 0 = x;
  lookupNat (x::rho) (i+1) = lookupNat rho i.

Define
  Agree(k,rho,tau) :=
    forall i<k, lookupNat rho i = lookupNat tau i.

No list-length assumption is required for the following invariance
lemmas.

L2N:
  a.wellScoped k=true and Agree(k,rho,tau)
  -> denoteN rho a = denoteN tau a.

Proof by induction on a.
A literal is independent of the environment. A scoped variable has
index i<k, so Agree supplies its equality. Successor and the three
binary arithmetic constructors preserve equality. QED.

L2R:
  a.wellScoped k=true and Agree(k,rho,tau)
  -> denoteR rho a = denoteR tau a.

Proof by induction on a.
Rationals are independent of the environment. Cast and actual symbols
use L2N to identify their arguments. Arithmetic, powers, and absolute
value preserve equality.

For sum bound body:
  L2N identifies the two finite bounds.
  For every summation index j,
    Agree(k+1,j::rho,j::tau).
  At index 0 both sides equal j; at index i+1 equality follows from
  Agree(k,rho,tau).
  Since body is scoped at k+1, its induction hypothesis identifies each
  summand. Equal bounds and equal summands identify the sums. QED.

L2F:
  F.wellScoped k=true and Agree(k,rho,tau)
  -> (Holds rho F <-> Holds tau F).

Proof by induction on F.
Atomic equality/order uses L2N or L2R. Top, bottom, conjunction, and
implication preserve the equivalence.
For forall Nat P, compare the bodies at n::rho and n::tau for each n.
Their environments agree at arity k+1 by the preceding argument. QED.

Corollary CLOSED:
  F.wellScoped 0=true
  -> forall rho, (Holds rho F <-> Holds [] F).
Agreement at arity zero is vacuous.

Corollary TRIM1:
  P.wellScoped 1=true
  -> (Holds [n+1,n] P <-> Holds [n+1] P).
Both environments have the same index-zero value.

Scope monotonicity also follows by structural induction:
  scoped k and k<=ell -> scoped ell.
For each binder, increase both scope bounds by one.

9. TOTAL BYTE ADMISSION FOR THE RESTRICTED FINITE CHECKER
======================================================================

The current archive contains no concrete decoder for its Proof datatype.
The following supplies a precise finite encoding design and its
mathematical correctness obligations.

9.1. Natural and integer encoding.

Use canonical base-128 unsigned varints:
  each byte contributes its low 7 bits;
  the high bit indicates another byte;
  the last byte has high bit 0;
  for encodings longer than one byte, the last 7-bit digit is nonzero.
Zero is encoded by one zero byte.

The value is sum_i digit_i*128^i.
Reject unterminated encodings and noncanonical redundant final zero
digits. The representation is unique.

Signed integers use zigzag:
  z>=0 -> 2z;
  z<0  -> -2z-1.
The inverse is determined by parity.

A rational uses encoded signed numerator and positive denominator.
Optional reduction to coprime form is deterministic; soundness requires
only the positive-denominator guard.

9.2. Tree encoding.

A constructor is encoded by its natural tag, followed by its scalar
fields and recursively encoded children in declaration order.

Fixed tag order:
  NExpr: lit,var,succ,add,mul,tsub.
  RExpr: rat,natCast,u,V,C,B,D,neg,add,mul,pow,abs,sum.
  Formula: top,bot,nEq,nLe,rEq,rLe,conj,impl,all.
  Frontier.Proof:
    hyp,triv,andI,andEL,andER,impI,impE,falseE,allI,allE,natInd,actualLeaf.
  ActualLeaf: momentBounds,marginStep,signRow.

Tags are numbered from zero in these displayed orders.
Lists/arrays are prefixed by their natural length.

SourcePacket is encoded by D,R,modeCutoff,J,P, followed by the
length-prefixed Ks list, in the exact order specified in Section 4.
The source-packet decoder validates this field layout and the stated
positive R,modeCutoff,J,P and list-length conditions. Exponential
inequality guards are checked by
the evaluator, not asserted by parsing.

The outer frame is the eight ASCII bytes RHFPRF01, followed by the
canonical varint payload length and exactly that many proof-tree bytes.
No bytes may follow this frame. The
decoder rejects unknown tags, incomplete fields, malformed varints,
shape mismatches, and unconsumed payload bytes.

This is a proposed new restricted-frontier format; it does not reinterpret
the legacy coordinate vector [1380464198,2,1,0,16,0].

9.3. Total parsing.

Use remaining input length as fuel.
Each varint byte step consumes one byte.
Each tree constructor first consumes at least its tag.
Every recursive child parser receives the strictly shorter remaining
input and rejects at exhausted fuel.
List parsing additionally decreases the stored remaining element count.

Thus the parser terminates for every finite ByteArray.
All natural arithmetic is arbitrary precision: a long varint is not
interpreted by overflowing machine arithmetic.

Let CodecWF(p) mean that every embedded rational has positive denominator
and every embedded source packet satisfies the structural field/list
conditions checked by the decoder. This does not assert numerical leaf
acceptance or any analytic proposition.

Structural induction proves:
  CodecWF(p) -> decode(encode(p))=some p,
with complete consumption for the framed canonical encoding.
The scalar base case is uniqueness of positional base-128 expansion;
the constructor case consumes the unique tag and applies each child
induction hypothesis in order.

For syntax failing CodecWF, rejection is permitted; no unconditional
roundtrip theorem for malformed syntax is claimed.

9.4. Restricted raw soundness.

For fixed closed target F, define
  verifyFrontier(blob,F) :=
    match decodeProof(blob) with
    | none => false
    | some p => checkFrontier 0 [] p F.

Then:
  verifyFrontier(blob,F)=true -> Holds [] F.
Proof: invert the decoder match, then apply E2.

The parser's roundtrip theorem establishes representability. Semantic
soundness requires only that accepted decoded syntax is passed to the
fixed checker.

For the finite target, take F=prefixGround Y M or F=rowGround M.
If Y,M are part of the outer packet, derive F from those same decoded
values. The packet must not independently select a different target.

10.1. Exact obstruction for this registry.

Every new actual leaf has a fixed finite bound on the moment indices it
constrains. The logical rules introduce no uniform analytic relation.
A finite proof therefore uses only a finite amount of actual moment
information.

For any prescribed prefix through K and Y>=0, choose n=max(16,K).
Keep that prefix, choose any remaining values through n, and write
u_(n+1)=T. Then
  B(n+1,j)=d_j+(-1)^(n+1-j)C(n+1,j)T.
Putting D=sum_j|d_j| yields
  V_(n+1)>=2^(n+1)T-D.
Choose integer T larger than
  [D+((n+1+Y)/(n+1))V_n]/2^(n+1).
Then C_n>YV_n, while all earlier moment constraints remain unchanged.

Thus finite ground actual leaves plus rules valid for arbitrary
sequences cannot derive the universal budget. This applies to the
finite leaf registry specified here.

The statement does not apply after a genuinely uniform actual-source
rule or full native analytic proof is added. Finite syntax can express
such a uniform theorem.
