EXACT IMPLEMENTED ROUTE

  finite rational coordinates
  + native actual-moment enclosure proof
  + exact rational margin/sign acceptance
  -> finite actual-xi admission.

  native universal-tail proof
  -> literal _root_.RiemannHypothesis.

  finite prefix proof + native tail proof
  -> frozen cutoff-16 admission
  -> literal _root_.RiemannHypothesis.

The complete native witness includes the proof of its universal tail.
No complete witness is supplied.

  actual MomentData.Encloses predicate and native proof admission;
  exact rational Bernstein evaluation;
  entrywise and row-variation error transport;
  marginCheck and signCheck;
  finite prefix aggregate checker;
  maximum-row sign propagation;

  actual degree-zero/one controls.

Not formalized in this package:
  the general rational theta-integral evaluator's soundness;
  arbitrary source-coefficient interval generation tied to AWPIRH.theta;
  the internal varint proof-byte codec from the B-tier specification;
  a useful coordinate-only universal tail checker.

The external JSON adapter emits literal Lean data and checks a supplied
closed native actual-moment proof. It is not an internal proof-byte
decoder theorem. The source evaluator gap is not hidden in a new axiom:
the precise actual enclosure proposition remains a named theorem input.

KEY ENDPOINTS

Tail16Admission.checkProof_sound:
  checkProof 0 [] p F = true -> Holds [] F.

Tail16Frontier.marginCheck_sound:
  d.Encloses (n+1)
  -> marginCheck d n Y = true
  -> BudgetStep Y n.

Tail16Frontier.signCheck_sound:
  d.Encloses M
  -> signCheck d M = true
  -> forall j<=M, actual Bernstein weight(M,j)>=0.

COORDINATE ADMISSION

The included example uses:
  examples/first_moment_sign.json
  examples/FirstMomentEvidence.lean

Execute from the extracted package directory:

  call admit.cmd "examples\first_moment_sign.json" "examples\FirstMomentEvidence.lean"

General interface:

  call admit.cmd "candidate.json" "ActualMomentProof.lean"

  call admit.cmd "candidate.json" "ActualMomentProof.lean" --tail-proof "UniversalTailProof.lean"

ActualMomentProof.lean must define the CLOSED theorem:

  SubmissionEvidence.encloses :
    SubmissionData.moments.Encloses SubmissionData.degree

UniversalTailProof.lean must define the CLOSED theorem:

  SubmissionTail.tail :
    Tail16Frontier.Tail
      SubmissionData.coefficient SubmissionData.tailCutoff

The data module is generated from canonical exact rationals.
Numerical acceptance uses kernel-checked norm_num proofs with explicit
finite-sum and rational normalization. Structural and logical controls
retain ordinary decide. No native_decide is used.
The resulting source is externally compiled and audited.
An optional RH root is additionally checked against a closed literal-RH
wrapper before the runner can report native RH admission.

No local proof hypothesis, sorryAx, or unapproved axiom may survive.
