ACCEPTED_WITNESS_PRESERVATION

  CertifiedDodgsonProjection K contains:

    cells : K.Cert -> List Dodgson.Cell,
    valid_of_accepted :
      forall c, K.check c=true -> AllValid(cells c).

  This is a fixed projection correctness proof, not a new universal RH-tail
  premise supplied for each submitted witness.

  The finite-cell theorem derives

    K.check c=true -> necessaryDodgsonTests K cells c=true.

  Therefore the following endpoints hold for a certified projection F:

    checkPruned K F.cells c = K.check c,

    checkPruned K F.cells c=true <-> K.check c=true,

    (exists c, checkPruned K F.cells c=true)
      <-> (exists c, K.check c=true),

    verifyPruned K F.cells decoder bytes = K.verify decoder bytes.

  No original accepted witness is lost under these explicit hypotheses.
  The empty certified projection is included as a concrete identity control.
  It performs no search reduction.

DODGSON_CELL_SCOPE

  A rational Cell contains:
    leftEntry, middleEntry, rightEntry, nextDet, pivot : Rat.

  turan(c) := leftEntry*rightEntry - middleEntry^2.

  Valid(c) :=
    nextDet*pivot=turan(c) /\ 0<nextDet /\ 0<pivot.

  necessaryTest(c) := decide(0<turan(c)).

  Valid(c) -> necessaryTest(c)=true.
  necessaryTest(c)=false -> not Valid(c).

  The recurrence identity alone does not discriminate between genuine Hankel
  moment sequences; every correctly computed determinant array satisfies it.
  Strict positivity supplies the exclusion condition used here.

  The separate recurrenceTest checks exact rational recurrence consistency.
  It is available as an additional diagnostic; the requested main presieve
  currently tests the necessary Turan positivity condition.

FAMILY_EXCLUSIONS

  geometricCell(a,q,nextDet,pivot):
    leftEntry=a, middleEntry=a*q, rightEntry=a*q^2.

  turan(geometricCell(...))=0.
  necessaryTest(geometricCell(...))=false.
  not Valid(geometricCell(...)).

  These conclusions hold for every rational a,q,nextDet,pivot.
  They exclude geometric triples only from the specified strict-positive
  cell class. Zero determinants can remain valid for unregularized
  semidefinite or finite-rank representations.

  If family(theta).turan <= U for every theta in region P and U<=0,
  then no family(theta) in P is Valid.

  For a certified projection F, a proved finite-test failure throughout a
  candidate region gives original-check rejection throughout that region.
