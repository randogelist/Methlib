  No checker, proof, semantic bridge, or RH hypothesis is an input to
  coordinateCheck.

FINITE_SPECIFICATION:
  spectralCutoff > 0
  etaSplit and near split denominators > 0
  0 < etaSplit <= 1
  near split = etaSplit as exact coordinate data
  tail cutoff = spectralCutoff
  exactly one compact cell
  all six cell rational denominators > 0
  left <= right; left <= etaSplit; 1 <= right
  g2Lower <= g2Upper; g3Lower <= g3Upper
  g2Upper < 0 OR 0 < g2Lower OR 0 < g3Lower
