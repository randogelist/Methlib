0. PURPOSE
----------

This file derives an exact computational bootstrap for extending the critical
H^(1/2) admission factor

  I

toward

  I -> infinity.

The principal mechanism is:

  current admission at factor I

  +

  certified local strong existence beyond the current QFB cutoff

  ->

  global regularity of the tested datum.

Applied to every datum in the next critical annulus, this yields the next
admission factor J > I.


1. IMPORTED OBJECTS
-------------------

Let

  H12SQ(b) := ||b||_{Ḣ^(1/2)}^2.

For I > 0 define the non-strict admission object

  ADMISSION(I)

by

  forall nu > 0,
  forall b in H^(1/2)_{sigma,0}(T^3),

    H12SQ(b) < 2*pi*I*nu^2

    ->

    Reg_nu(b).

The previously frozen strict improvement object is

  IMPROVEMENT(I) := I > 1 and ADMISSION(I).

The baseline is

  ADMISSION(1).

For a in L^2_{sigma,0}(T^3), define

  T_I(a,nu)
  := ||a||_2^4 / (8*pi^2*I^2*nu^5).

The imported H12_SIGMA_0_RESTR adapter is

  ADMISSION(I)

  ->

  forall a in L^2_{sigma,0},
  forall u in LH_nu(a),
  forall delta > T_I(a,nu),

    u is smooth on [delta,infinity) x T^3.


2. DOWNWARD MONOTONICITY
------------------------

If

  0 < J <= I

and

  ADMISSION(I),

then

  ADMISSION(J).

Proof:

  H12SQ(b) < 2*pi*J*nu^2

  <= 2*pi*I*nu^2.

Therefore the set

  A := { I > 0 : ADMISSION(I) }

is downward closed.

Define the extended admission extent

  I_STAR := sup A

in the extended nonnegative reals.

Then, up to the strict-boundary convention,

  ADMISSION(I)  for every finite I < I_STAR.


3. UNBOUNDED-ADMISSION CLOSURE
------------------------------

Define

  UNBOUNDED_ADMISSION

by the existence of a sequence I_n such that

  forall n, I_n > 0,
  forall n, ADMISSION(I_n),
  forall M > 0, exists n, M < I_n.

Define

  H12_GLOBAL_REGULARITY

by

  forall nu > 0,
  forall b in H^(1/2)_{sigma,0}(T^3),

    Reg_nu(b).

The exact equivalence is

  UNBOUNDED_ADMISSION

  <->

  H12_GLOBAL_REGULARITY.

Forward proof:

  Fix nu > 0 and b in H^(1/2)_{sigma,0}.

  Put

    M := H12SQ(b) / (2*pi*nu^2).

  Choose n with

    I_n > M.

  Then

    H12SQ(b) < 2*pi*I_n*nu^2.

  Apply ADMISSION(I_n).

Reverse proof:

  H12_GLOBAL_REGULARITY implies ADMISSION(I) for every finite I > 0.

Consequently

  I_STAR = infinity

  <->

  H12_GLOBAL_REGULARITY.

Under the standard Fujita-Kato local/restart adapter and the mean/Galilean
adapter already used for the periodic formulation,

  H12_GLOBAL_REGULARITY

  <->

  NSE_B.

Thus

  I_STAR = infinity

  <->

  NSE_B.

4. CRITICAL ANNULUS OBJECT
--------------------------

For 0 < I < J define

  SHELL(I,J,nu)

by

  { b in H^(1/2)_{sigma,0} :

      2*pi*I*nu^2 <= H12SQ(b)

      and

      H12SQ(b) < 2*pi*J*nu^2 }.

Define

  SHELL_REGULAR(I,J)

by

  forall nu > 0,
  forall b in SHELL(I,J,nu),

    Reg_nu(b).

Then

  ADMISSION(I)
  and
  SHELL_REGULAR(I,J)

  ->

  ADMISSION(J).

Proof:

  Every b below the J-threshold lies either below the I-threshold or inside
  SHELL(I,J,nu).

5. LOCAL STRONG WINDOW
----------------------

Define

  STRONG_WINDOW_nu(b,tau)

by

  tau > 0

  and

  the NSE datum b generates a unique strong critical solution on [0,tau],
  with the weak-strong uniqueness and restart compatibility required to glue
  it to a Leray-Hopf trajectory.

Define the overlap margin

  OVERLAP_MARGIN(I,b,nu,tau)
  := tau - T_I(b,nu).

Define

  QFB_OVERLAP(I,b,nu)

by

  exists tau > T_I(b,nu),

    STRONG_WINDOW_nu(b,tau).


6. DATUMWISE OVERLAP LEMMA
--------------------------

Assume

  ADMISSION(I)

and

  QFB_OVERLAP(I,b,nu).

Then

  Reg_nu(b).

Proof:

  Choose tau such that

    tau > T_I(b,nu)

  and

    STRONG_WINDOW_nu(b,tau).

  Choose delta with

    T_I(b,nu) < delta < tau.

  Let u be a Leray-Hopf solution with datum b.

  By the QFB adapter induced by ADMISSION(I),

    u is smooth on [delta,infinity).

  By STRONG_WINDOW_nu(b,tau) and weak-strong uniqueness,

    u agrees on [0,delta]

  with the unique local strong solution.

  The two strong pieces agree at delta and form a global strong trajectory.

  Therefore

    Reg_nu(b).

Frozen endpoint:

  QFB_OVERLAP_REGULARITY:

    ADMISSION(I)
    and
    STRONG_WINDOW_nu(b,tau)
    and
    T_I(b,nu) < tau

    ->

    Reg_nu(b).

10. DIMENSIONLESS MASS-RATIO FORM
---------------------------------

Define

  THETA_I(b,nu)
  := ||b||_2^2 / (2*pi*I*nu^2).

Then the QFB cutoff has the exact form

  T_I(b,nu)
  = THETA_I(b,nu)^2 / (2*nu).

Proof:

  THETA_I(b,nu)^2 / (2*nu)

  = ||b||_2^4
    /
    (8*pi^2*I^2*nu^5).

Therefore the overlap test is exactly

  2*nu*tau

  >

  THETA_I(b,nu)^2.

Define the overlap index

  OMEGA_I(b,nu,tau)
  := 2*nu*tau / THETA_I(b,nu)^2

when THETA_I(b,nu) > 0.

Then

  OMEGA_I(b,nu,tau) > 1

is equivalent to

  tau > T_I(b,nu).

This is the preferred computational scalar certificate.

For b = 0, regularity is immediate and the overlap quotient is unnecessary.

11. POINCARE SHELL BOUND
------------------------

Let C_P be the squared-norm Poincare constant satisfying

  ||b||_2^2

  <=

  C_P * H12SQ(b)

for mean-zero data.

For

  b in SHELL(I,J,nu),

one has

  ||b||_2^2

  <

  2*pi*C_P*J*nu^2.

Hence

  THETA_I(b,nu)

  <

  C_P * J/I

and

  T_I(b,nu)

  <

  C_P^2 * J^2 / (2*I^2*nu).

Thus a sufficient uniform shell certificate is

  forall b in SHELL(I,J,nu),

    STRONG_WINDOW_nu
    (
      b,
      tau_shell
    )

with

  tau_shell

  >=

  C_P^2 * J^2 / (2*I^2*nu)

and strict inequality at the final overlap comparison.

Important boundary:

  If J/I remains bounded away from zero, this worst-case shell cutoff is only
  O(1/nu).  It does not automatically tend to zero as I grows.

  The I^(-2) gain applies datumwise at fixed L^2 mass.  Expanding the shell can
  increase the admissible L^2 mass and offset that gain.

Therefore a successful extension requires more information than the shell
H^(1/2) radius alone.

Let C be a certified subset of SHELL(I,J,nu).

13. NONCOMPACTNESS BOUNDARY
---------------------------

A bounded shell in H^(1/2) is not compact in the H^(1/2) topology.

Therefore a direct finite H^(1/2)-ball cover of SHELL(I,J,nu) is unavailable.

A valid finite computational cover requires an additional reduction, such as:

  (A) finite low-mode cells plus a uniform analytic tail theorem;

  (B) profile decomposition plus finitely many normalized profile cells;

  (C) symmetry or structural classes with certified orbit access;

  (D) a nonlinear-defect reduction placing the residual in a stable class;

  (E) a critical-element compactness theorem followed by rigidity.

Define the required reduction abstractly as

  COMPUTATIONAL_REDUCTION(I,J)

meaning:

  every b in SHELL(I,J,nu) is assigned to one of finitely many certified
  normalized cells, together with analytic residual data sufficient to
  transfer the cell's local strong window to b.

Then

  COMPUTATIONAL_REDUCTION(I,J)

  +

  CELL_OVERLAP for every normalized cell

  ->

  OVERLAP_SHELL(I,J).

The reduction is an explicit unresolved endpoint.  It may not be silently
replaced by finite-dimensional truncation alone.


14. STRUCTURAL EFFECTIVE-GAIN VARIANT
-------------------------------------

Let R_n be structural predicates, let I_n > 0, and let rho_n in (0,1].

Assume

  ADMISSION restricted to R_n at factor I_n

and

  uniform orbit-access density rho_n.

The structural QFB cutoff is

  T_n(a,nu)

  :=

  ||a||_2^4
  /
  (8*pi^2*rho_n*I_n^2*nu^5).

Define

  EFFECTIVE_GAIN_n

  := rho_n*I_n^2.

If

  EFFECTIVE_GAIN_n -> infinity,

then, for fixed a and nu,

  T_n(a,nu) -> 0.

Hence every Leray-Hopf trajectory is smooth on [delta,infinity) for every
fixed delta > 0.

For smooth or H^(1/2) initial data, the ordinary local strong interval fills
the initial endpoint and weak-strong uniqueness glues the positive-time tail.
Thus, under uniform structural hypotheses,

  EFFECTIVE_GAIN_n -> infinity

  ->

  NSE_B.

Since rho_n <= 1,

  EFFECTIVE_GAIN_n -> infinity

still implies

  I_n -> infinity.

Its advantage is not avoidance of unbounded threshold factors.  Its advantage
is that each unbounded factor may be proved only on a structured sector rather
than on the entire critical ball.
