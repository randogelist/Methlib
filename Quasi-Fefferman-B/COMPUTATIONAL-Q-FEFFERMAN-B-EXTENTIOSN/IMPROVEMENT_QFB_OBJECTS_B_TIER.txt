0. SCOPE
--------

Domain:

  T^3 := three-dimensional periodic torus.

Data spaces:

  H12_sigma_0 := H^(1/2)_{sigma,0}(T^3),
  L2_sigma_0  := L^2_{sigma,0}(T^3).

Viscosity:

  nu > 0.

Homogeneous critical quantity:

  H12SQ(b) := ||b||_{Ḣ^(1/2)}^2.

Baseline squared threshold:

  Lambda_0 := 2*pi.

All constant formulas below use this normalization.


1. ROOT OBJECTS
---------------

1.1 REGULARITY OBJECT

  Reg_nu(b)

means:

  the datum b in H12_sigma_0 generates a global strong NSE solution in the
  canonical critical class, smooth for every positive time, with the standard
  restart and weak-strong uniqueness consequences required below.


1.2 LERAY-HOPF OBJECT

  LH_nu(a)

means:

  the set of Leray-Hopf solutions u with viscosity nu and initial datum
  a in L2_sigma_0.


1.3 TRAJECTORYWISE QFB OBJECT

For tau >= 0 define

  QFB_nu(a, tau)

by

  forall u in LH_nu(a),
  forall delta > tau,
  u is smooth on [delta, infinity) x T^3.

This object is trajectorywise.  It does not assert equality of two Leray-Hopf
solutions on an interval preceding their respective regular restart times.


2. FROZEN IMPROVEMENT HYPOTHESIS
--------------------------------

For I > 1 define

  IMPROVEMENT(I)

by

  forall nu > 0,
  forall b in H12_sigma_0,

    H12SQ(b) < 2*pi*I*nu^2

    implies

    Reg_nu(b).

Equivalent threshold notation:

  Lambda_I := 2*pi*I.

Hence

  IMPROVEMENT(I)

is exactly

  H12SQ(b) < Lambda_I*nu^2  ->  Reg_nu(b).

Baseline:

  I = 1,
  Lambda_1 = 2*pi.

Strict improvement:

  I > 1.

Critical norm radius:

  Radius_I(nu) := sqrt(2*pi*I)*nu.

Radius gain relative to baseline:

  Radius_I(nu) / Radius_1(nu) = sqrt(I).


3. LERAY-HOPF QUARTIC BUDGET
----------------------------

Let

  a in L2_sigma_0,
  u in LH_nu(a).

Energy inequality:

  ||u(t)||_2^2
  + 2*nu * integral_0^t ||u(s)||_{Ḣ^1}^2 ds
  <= ||a||_2^2.

Consequences:

  sup_{t >= 0} ||u(t)||_2^2 <= ||a||_2^2,

  integral_0^infinity ||u(t)||_{Ḣ^1}^2 dt
  <= ||a||_2^2 / (2*nu).

Fourier interpolation:

  ||u(t)||_{Ḣ^(1/2)}^2
  <= ||u(t)||_2 * ||u(t)||_{Ḣ^1}.

Squaring:

  ||u(t)||_{Ḣ^(1/2)}^4
  <= ||u(t)||_2^2 * ||u(t)||_{Ḣ^1}^2.

Integration gives the quartic critical budget

  integral_0^infinity ||u(t)||_{Ḣ^(1/2)}^4 dt
  <= ||a||_2^4 / (2*nu).

Define

  LH_BUDGET(a, nu) := ||a||_2^4 / (2*nu).

Thus

  integral_0^infinity H12SQ(u(t))^2 dt
  <= LH_BUDGET(a, nu).


4. IMPROVEMENT ENTRY-TIME OBJECT
--------------------------------

Threshold square:

  THRESHOLD_SQ(I, nu)
  := (2*pi*I*nu^2)^2
   = 4*pi^2*I^2*nu^4.

Assume that for almost every admissible Leray-Hopf restart time t in (0,T),

  H12SQ(u(t)) >= 2*pi*I*nu^2.

Then

  integral_0^T H12SQ(u(t))^2 dt
  >= 4*pi^2*I^2*nu^4*T.

The quartic budget therefore forces

  4*pi^2*I^2*nu^4*T
  <= ||a||_2^4 / (2*nu).

Equivalently,

  T <= ||a||_2^4 / (8*pi^2*I^2*nu^5).

Hence every

  T > ||a||_2^4 / (8*pi^2*I^2*nu^5)

contains an admissible restart time s in (0,T) satisfying

  H12SQ(u(s)) < 2*pi*I*nu^2.

Define the computational cutoff object

  QFB_CUTOFF(a, nu, I)
  := ||a||_2^4 / (8*pi^2*I^2*nu^5).


5. H12_SIGMA_0_RESTR ADAPTER
----------------------------

Assume

  IMPROVEMENT(I).

Let

  a in L2_sigma_0,
  u in LH_nu(a),
  delta > QFB_CUTOFF(a, nu, I).

Choose T with

  QFB_CUTOFF(a, nu, I) < T < delta.

By Section 4 there exists an admissible restart time s in (0,T) such that

  H12SQ(u(s)) < 2*pi*I*nu^2.

By IMPROVEMENT(I),

  Reg_nu(u(s)).

By restart compatibility and weak-strong uniqueness, the Leray-Hopf trajectory
u agrees from time s onward with the global strong trajectory generated by
u(s).

Since

  s < T < delta,

the trajectory u is smooth on

  [delta, infinity) x T^3.

Therefore

  IMPROVEMENT(I)

implies

  QFB_nu(a, QFB_CUTOFF(a, nu, I)).

Frozen adapter theorem:

  H12_SIGMA_0_RESTR_ADAPTER:

  forall I > 1,

    IMPROVEMENT(I)

    ->

    forall nu > 0,
    forall a in L2_sigma_0,

      QFB_nu
      (
        a,
        ||a||_2^4 / (8*pi^2*I^2*nu^5)
      ).

6. CONSTANTS TRANSLATION
------------------------

Baseline cutoff:

  QFB_CUTOFF(a, nu, 1)
  = ||a||_2^4 / (8*pi^2*nu^5).

Improved cutoff:

  QFB_CUTOFF(a, nu, I)
  = I^(-2) * QFB_CUTOFF(a, nu, 1).

QFB gain:

  QFB_GAIN(I)
  := QFB_CUTOFF(a, nu, 1) / QFB_CUTOFF(a, nu, I)
   = I^2.

Thus

  squared H^(1/2)-threshold gain  I

implies

  QFB cutoff gain  I^2.

Equivalently, with critical-radius gain

  gamma := sqrt(I),

one has

  I = gamma^2,

  QFB_CUTOFF(a, nu, I)
  = gamma^(-4) * QFB_CUTOFF(a, nu, 1).

Hence

  H^(1/2)-radius gain gamma

implies

  quartic QFB time gain gamma^4.

Monotonicity:

  1 < I_1 <= I_2

implies

  QFB_CUTOFF(a, nu, I_2)
  <= QFB_CUTOFF(a, nu, I_1).

Inverse translation:

  I
  = sqrt
    (
      QFB_CUTOFF(a, nu, 1)
      /
      QFB_CUTOFF(a, nu, I)
    ).

For a prescribed cutoff tau > 0,

  QFB_CUTOFF(a, nu, I) <= tau

is equivalent to

  I >= ||a||_2^2
       /
       (2*sqrt(2)*pi*nu^(5/2)*sqrt(tau)).


7. NONLINEAR-COEFFICIENT TRANSLATION
------------------------------------

Suppose the restricted critical estimate has the form

  (1/2) d/dt ||v||_{Ḣ^(1/2)}^2

  +

  (nu - C_RESTR*||v||_{Ḣ^(1/2)})
  ||v||_{Ḣ^(3/2)}^2

  <= 0.

The associated norm radius is

  ||b||_{Ḣ^(1/2)} < nu / C_RESTR.

The associated squared threshold is

  H12SQ(b) < nu^2 / C_RESTR^2.

Identification with IMPROVEMENT(I):

  nu^2 / C_RESTR^2
  = 2*pi*I*nu^2.

Therefore

  I = 1 / (2*pi*C_RESTR^2),

  C_RESTR = 1 / sqrt(2*pi*I).

The QFB cutoff becomes

  QFB_CUTOFF(a, nu, I)
  = C_RESTR^4 * ||a||_2^4 / (2*nu^5).

Coefficient improvement:

  C_RESTR decreases

implies

  I increases

and therefore

  QFB_CUTOFF decreases quartically in C_RESTR.


8. STRUCTURAL RESTRICTION VARIANT
---------------------------------

Let R be a structural predicate on H12_sigma_0.

Define

  IMPROVEMENT_R(I)

by

  forall nu > 0,
  forall b in H12_sigma_0,

    R(b)
    and
    H12SQ(b) < 2*pi*I*nu^2

    implies

    Reg_nu(b).

This hypothesis alone does not imply the universal QFB cutoff, because a
general Leray-Hopf trajectory need not enter R.

Define orbit-access density rho in (0,1] by

  measure
  {
    t in (0,T) :
    t is an admissible restart time and R(u(t))
  }

  >= rho*T.

If no R-admissible time in (0,T) satisfies the improved threshold, then

  integral_0^T H12SQ(u(t))^2 dt
  >= rho*T*4*pi^2*I^2*nu^4.

Therefore the structural cutoff is

  QFB_CUTOFF_R(a, nu, I, rho)
  := ||a||_2^4 / (8*pi^2*rho*I^2*nu^5).

Frozen structural adapter:

  IMPROVEMENT_R(I)
  and
  ORBIT_ACCESS(R, rho)

  imply

  QFB_nu
  (
    a,
    QFB_CUTOFF_R(a, nu, I, rho)
  ).

Pure threshold adapter:

  R := True,
  rho := 1.
