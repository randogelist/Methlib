1. EXACT ACCEPTED SCOPE

For every finite type n with Fintype n and DecidableEq n, and matrices
A,B : Matrix n n Real, assume all entries of A and B are nonnegative.
The accepted root gives the exact permanent residual, Hadamard permanent
inequality, and complete equality classification. Its normalization branch
is quantified under positive-permanent antecedents. These assumptions define
the theorem's domain; they are not unresolved construction obligations.

Let a_sigma=product_i A(i,sigma(i)), b_sigma=product_i B(i,sigma(i)),
P=per(A), Q=per(B), and Delta=P*Q-per(A o B). Then
  Delta=sum_(sigma!=tau) a_sigma*b_tau >= 0,
  per(A o B)<=per(A)*per(B),
  Delta=0 iff P=0 or Q=0 or common unique positive permutation support.
Common unique positive support means an index kappa with a_kappa,b_kappa>0
and a_rho=b_rho=0 for every rho!=kappa.
For P,Q>0, pi_A=a/P and pi_B=b/Q have mass one and
  per(A o B)/(P*Q)=sum_sigma pi_A(sigma)*pi_B(sigma),
  Delta/(P*Q)=1-sum_sigma pi_A(sigma)*pi_B(sigma).
The overlap is in [0,1] and equals one exactly for common singleton support.
Finite nonnegative weighted-Gram specialization is also among the audited
theorems. No positive-semidefiniteness assumption is needed for this root.

2. EXACT NATIVE ROOT SIGNATURE

Namespace: AIM025.
Implicit parameters: {n : Type*} [Fintype n] [DecidableEq n].

theorem AIM025_CHOLLET_NONNEGATIVE
    (A B : Matrix n n ℝ)
    (hA : ∀ i j, 0 ≤ A i j) (hB : ∀ i j, 0 ≤ B i j) :
    cholletGap A B = offDiagonalPair (permTerm A) (permTerm B) ∧
    Matrix.permanent (Matrix.hadamard A B) ≤
      Matrix.permanent A * Matrix.permanent B ∧
    (cholletGap A B = 0 ↔
      Matrix.permanent A = 0 ∨ Matrix.permanent B = 0 ∨
        CommonUniquePositive (permTerm A) (permTerm B)) ∧
    (0 < Matrix.permanent A → 0 < Matrix.permanent B →
      (∑ σ, permutationDistribution A σ) = 1 ∧
      (∑ σ, permutationDistribution B σ) = 1 ∧
      Matrix.permanent (Matrix.hadamard A B) /
          (Matrix.permanent A * Matrix.permanent B) =
        diagonalPair (permutationDistribution A) (permutationDistribution B) ∧
      cholletGap A B / (Matrix.permanent A * Matrix.permanent B) =
        1 - diagonalPair (permutationDistribution A) (permutationDistribution B) ∧
      (0 ≤ diagonalPair (permutationDistribution A) (permutationDistribution B) ∧
        diagonalPair (permutationDistribution A) (permutationDistribution B) ≤ 1) ∧
      (diagonalPair (permutationDistribution A) (permutationDistribution B) = 1 ↔
        CommonUniquePositive (permTerm A) (permTerm B)))
