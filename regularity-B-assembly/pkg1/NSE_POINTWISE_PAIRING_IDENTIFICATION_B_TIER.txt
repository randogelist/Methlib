======================================================================
1. EXACT SCOPED THEOREM
======================================================================

Let T^3 = (R/Z)^3.

Let u : T^3 -> R^3 be a sufficiently regular periodic divergence-free
vector field. Let

  J(x) := grad u(x),
  w(x) := Lambda u(x),

where Lambda = (-Delta)^(1/2), and define

  B(u,u)(x) := (u(x) dot grad)u(x) = J(x)u(x).

Let P be the periodic Leray projection and define

  Iabs(u)
    := abs (integral_T3 inner(P(B(u,u))(x),w(x)) dx).

Assume the scalar magnitude functions

  f(x)=|u(x)|,
  g(x)=|J(x)|_F,
  h(x)=|w(x)|

belong to L^3(T^3).

Then

  Iabs(u) <= ||f||_L3 ||g||_L3 ||h||_L3.

Equivalently, for the critical state

  s.U3   = ||u||_L3,
  s.G3   = ||grad u||_L3,F,
  s.L3   = ||Lambda u||_L3,
  s.Iabs = Iabs(u),

one has

  CriticalHolder(s):
    s.Iabs <= s.U3*s.G3*s.L3.

No periodic Sobolev embedding is used here. The theorem converts the actual
NSE nonlinear pairing into the abstract Holder input.

======================================================================
2. MATRIX FORM AND POINTWISE ADVECTION BOUND
======================================================================

Write J_ij=partial_j u_i. Then

  B_i = sum_j J_ij u_j,

so B=Ju.

For every i, finite-dimensional Cauchy-Schwarz gives

  |B_i|^2
    <= (sum_j |J_ij|^2)(sum_j |u_j|^2).

Summing over i yields

  |B|^2 <= |J|_F^2 |u|^2,

and therefore

  |B| <= |J|_F |u|.

Coordinate-free form:

  |Ju| <= ||J||_op |u| <= ||J||_F |u|.

======================================================================
3. POINTWISE PAIRING BOUND
======================================================================

Cauchy-Schwarz in R^3 gives

  |inner(B,w)| <= |B||w|.

Hence

  |inner(B,w)| <= |u||J|_F|w|.

With f=|u|, g=|J|_F and h=|w|,

  |inner(B,w)| <= fgh.

======================================================================
4. LERAY AND PRESSURE CANCELLATION
======================================================================

Since u is divergence-free and Lambda is a scalar Fourier multiplier,

  div(Lambda u)=Lambda(div u)=0.

Thus w=Lambda u is divergence-free. The Leray projection is the L^2
orthogonal projection onto divergence-free fields, so

  inner_L2(PB,w)=inner_L2(B,w).

Equivalently, the pressure contribution satisfies

  integral_T3 inner(grad p,w)
    = - integral_T3 p div(w)
    = 0.

Therefore

  Iabs(u)=abs(integral_T3 inner(B,w)).

======================================================================
5. INTEGRAL DOMINATION AND HOLDER
======================================================================

The integral triangle inequality and the pointwise estimate give

  Iabs(u)
    <= integral_T3 |inner(B,w)|
    <= integral_T3 fgh
    = ||fgh||_L1.

Holder with exponents (3,3,3) gives

  ||fgh||_L1
    <= ||f||_L3 ||g||_L3 ||h||_L3.

Thus

  Iabs(u)
    <= ||u||_L3 ||grad u||_L3,F ||Lambda u||_L3.

This is exactly CriticalHolder(s).
