1. EXACT FORMAL DOMAIN

  Mode3 = Fin 3 -> Z; CVec3 = EuclideanSpace C (Fin 3).
  lambda(k) = 2*pi*|k|.
  Q(a) = sum'_k lambda(k)*|a(k)|^2; N(a) = sqrt(Q(a)).

  RealH12Datum consists of a coefficient map a : Mode3 -> CVec3 with:
    a(0) = 0;
    a(k) in solenoidalSubmodule(k), for every k;
    Summable (k |-> lambda(k)*|a(k)|^2);
    a(-k)_i = conjugate(a(k)_i), for every k and i.

  Real-valuedness is conjugation symmetry; individual coefficients need
  not be real. This carrier is a concrete weighted Fourier sequence class.
  Physical Fourier synthesis, physical Sobolev identification, and an NSE
  evolution are not fields of RealH12Datum.

  smallRadius(nu,C3) = nu/(8*C3^3).
  Small(nu,C3,a) :=
    0 < nu and 0 < C3 and Q(a) < smallRadius(nu,C3)^2.
  SmallDatum(nu,C3) = {a : RealH12Datum // Small(nu,C3,a)}.

  C3 is a numerical parameter here. Existence of a physical periodic
  Sobolev certificate with constant C3 remains a separate theorem.

2. CONCRETE CARRIER ENDPOINTS

  H12SigmaZeroSmallClass.H12_SIGMA_ZERO_SMALL_CLASS:
    For nu,C3 > 0, SmallDatum(nu,C3) is nonempty.
    Heat multiplication exp(-nu*lambda(k)^2*t), t >= 0, preserves Small.
    Every finite cutoff S with (-k in S iff k in S) preserves Small.

  Auxiliary conclusions:
    Q(a) >= 0; N(a) >= 0; N(a)^2 = Q(a).
    Small(nu,C3,a) implies N(a) < nu/(8*C3^3).
    Q(heat(a)) <= Q(a); Q(cutoff_S(a)) <= Q(a).

  H12SmallScaling.H12_SMALL_SCALING:
    Q(r*a) = r^2*Q(a), for real r.
    |r| <= 1 and Small(nu,C3,a) imply Small(nu,C3,r*a).
    For nu,C3 > 0, a nonzero Small(nu,C3,a) exists.

  H12SmallScaling.criticalNorm_scale:
    N(r*a) = |r|*N(a).

  H12SmallScaling.exists_small_positive_scale:
    For every RealH12Datum a and nu,C3,epsilon > 0,
    there exists r with 0 < r < epsilon and Small(nu,C3,r*a).

  The explicit nonzero datum has support at +e_1 and -e_1 and equal
  transverse real coefficients in the e_2 direction. Positive rescaling
  supplies nonzero data inside every positive smallRadius.

3. COEFFICIENT L2 EMBEDDING AND DEFINITENESS

  H12L2CoefficientEmbedding.physical_frequency_gap:
    k != 0 implies 2*pi <= lambda(k).

  H12L2CoefficientEmbedding.H12_L2_COEFFICIENT_EMBEDDING:
    For every a : RealH12Datum,
      Summable (k |-> |a(k)|^2),
      sum'_k |a(k)|^2 <= Q(a)/(2*pi),
      Q(a) = 0 iff (forall k, a(k) = 0).

  H12L2CoefficientEmbedding.criticalNorm_eq_zero_iff:
    N(a) = 0 iff (forall k, a(k) = 0).

  Mean zero removes the zero-frequency obstruction. These conclusions
  concern coefficient sums. Physical L2 synthesis, real-valuedness, weak
  divergence zero, and norm identification remain separate endpoints.

4. SCALAR CRITICAL ENERGY THEOREMS

  H,D,E,d : R -> R; nu,C > 0; theta < 1; T,H0 >= 0.
  kappa = 2*(1-theta)*nu > 0.

  H12CriticalEnergyBudget.H12_CRITICAL_ENERGY_OF_SMALL_DATA:
    H,D continuous on [0,T]; H,D >= 0 on [0,T];
    H'(t) = d(t) for 0 <= t < T;
    H(0) <= H0;
    C*sqrt(H0) <= theta*nu;
    d(t)+2*nu*D(t) <= 2*C*sqrt(H(t))*D(t), 0 <= t < T;
    imply, for every 0 <= t <= T,
      H(t)+kappa*integral_0^t D(s) ds <= H0.

  Persistence H(t) <= H0 is derived by a barrier argument, not assumed.
  Derivatives at t=0 are required; derivatives at t=T are not.

  H12CriticalEnergyBudget.H12_SQUARE_ENSTROPHY_OF_SMALL_DATA:
    Add E continuous on [0,T] and E(t)^2 <= H(t)*D(t). Then
      integral_0^T E(t)^2 dt <= H0^2/[2*(1-theta)*nu].

  H12CriticalEnergyBudget.H12_UNIFORM_SQUARE_ENSTROPHY_OF_SMALL_DATA:
    The preceding implication holds uniformly for any indexed family
    (H_n,D_n,E_n,d_n) with common nu,C,theta,T,H0.

  H12CriticalEnergyBudget.H12_SQUARE_ENSTROPHY_OF_CRITICAL_ENERGY:
    An integrated energy inequality H+kappa*integral D <= H0,
    nonnegative H,D, continuous D,E, and E^2 <= H*D imply
      H(t) <= H0; integral_0^T D <= H0/kappa;
      integral_0^T E^2 <= H0^2/kappa.

  H12CriticalEnergyBudget.H12_UNIFORM_SQUARE_ENSTROPHY_OF_CRITICAL_ENERGY:
    The preceding square budget holds uniformly in an arbitrary index.

5. CONCRETE ADMISSION TO THE SCALAR BUDGET

  H12SmallClassBudget.small_critical_coefficient_le:
    Small(nu,C3,a) implies C3^3*sqrt(Q(a)) <= nu/4.

  H12SmallClassBudget.H12_SMALL_CLASS_UNIFORM_SQUARE_ENSTROPHY:
    Given a : RealH12Datum with Small(nu,C3,a), put H0=Q(a), C=C3^3,
    theta=1/4. For every indexed scalar family satisfying the continuity,
    nonnegativity, derivative, initial comparison, differential law, and
    interpolation premises of Section 4,
      integral_0^T E_n(t)^2 dt
        <= Q(a)^2/[2*(1-1/4)*nu] = 2*Q(a)^2/(3*nu), for every n.

  H12SmallClassBudget.H12_SMALL_CLASS_EXISTS_UNIFORM_BUDGET:
    Under exactly these premises, there exists a nonnegative common M
    bounding every integral_0^T E_n^2. The constructed witness is
      M = Q(a)^2/[2*(1-1/4)*nu].

  This bound is independent of the index n and terminal time T.
  The hypotheses must hold on the interval under consideration.
  Initial smallness follows from membership in Small. Persistence and
  existence of the scalar budget are conclusions, not input premises.

  Intended physical substitutions:
    H_n(t) = ||u_n(t)||_{dot H^(1/2)}^2,
    D_n(t) = ||u_n(t)||_{dot H^(3/2)}^2,
    E_n(t) = ||grad u_n(t)||_2^2,
    d_n(t) = d/dt H_n(t).

  Sections 4-5 do not construct u_n or prove these substitutions.
  Scalar conclusions alone supply neither a physical Galerkin estimate,
  AX6 admission, nor continuum regularity.
